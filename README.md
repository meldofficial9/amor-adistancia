# Amor a Distancia 💌 (React + Vite + Tailwind)

Romantic page lista para Netlify:
- Sobre/carta con animación
- Galería de fotos con textos editables
- Música romántica (URL o subir archivo)
- Mini‑juego por fases con preguntas/respuestas
- Panel de Configuración con Exportar/Importar JSON (se guarda en localStorage)

## Uso rápido
```bash
npm i
npm run dev
```
## Build & Deploy
- Conecta tu repo a **Netlify** → build `npm run build` → publish dir `dist`.

## Personalización
En la página: botón **Configurar**, sección **Recuerdos** y **Juego**.
